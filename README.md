# Timeline
In Spring 2023, I attended a course for Web Development held by CodePath, where the end assignment involved producing a webpage centered on a first-world problem of your choosing. As it is still an ongoing issue and is something that has become a big fear of mine, I decided to choose Police Brutality as my topic. Throughout the course, I learned the basics of HTML, CSS, & JS and used those skills to build the initial foundation of my webpage.
In Spring 2025, I attended another intermediate course for Web Development, also with CodePath, where they focused on the frontend and backend of programming. Throughout this course, I learned how to use React.js, as well as how to use backend services like Supabase and web APIs like Spotify and Last.fm. I gained more of an interest in web development after this course and started to favor React.js over HTML, so I shifted this original project from an HTML based project to a React based one.
## Design & Prototyping
### Canva 
- Before starting the beginner web development course, we were assigned to create a wireframe of our webpage.
- The wireframe was used as a foundation for the original project.
(https://canva.link/xrwl6wmjg1cu4xo)
### HTML, CSS, JS
- Used container divs to separate sections of the site between each other (header, content, footer, etc.)
- Used list containers (ul & li) to create a navigation bar for improved interaction (with Javascript)
    - Kept fixed on the screen after scrolling past (with CSS & JS)
- Created content pages (videos and articles) for more accessibility (with Javascript)
### React.js
- Updated UI to a more professional news-site look
- Created library pages to hold all related content contained within the database
- Allows users to upload their own stories and submit them to be uploaded to the web page
    - User's name can be included or anonymous
    - Any supporting media (links, pictures, videos, etc.) can be included
### Supabase
- Different tables created to hold all content within the webpage
    - Articles, Videos, People & Stories
- Contains a bin that holds all files/links shared by users
- All shared stories are held until they are approved for upload
### Media
- All written media (videos, articles, and people) written and submitted by me.
